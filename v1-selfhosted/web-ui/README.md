# LiveSMS v1: web UI

Vue 2 + TypeScript + Tailwind single-page app. `VUE_APP_API_ROOT` and `VUE_APP_WS_ROOT` (see `.env.*`) point it at the API.
See the [top-level README](../../README.md) for the architecture.

```sh
npm install
npm run serve   # development
npm run build   # production bundle in dist/, served by the nginx image
```
